Data Engineering Mastery Curriculum

Production-Ready • AI-Augmented • Portfolio-Driven

Duration: 12 weeks (extendable to 16) Commitment: 12–15 hours/week Goal: Junior / Associate Data Engineer ready

Philosophy

Vibe-coding is a powerful multiplier — never a substitute for understanding. Docker is introduced from Week 1 and used throughout. Every major skill is proven through real, hiring-relevant projects.

Core Tracks

Track I Technical Foundations — Docker • Advanced SQL • Data Modeling • Production Python

Track II Modern Data Stack — dbt • Orchestration (Prefect/Airflow) • Data Quality • Incremental Pipelines

Track III Cloud & Production Thinking — Cloud (BigQuery / AWS) • Observability • Documentation • System Design

Track IV Portfolio & Career — Flagship projects • GitHub excellence • Interview preparation • Applications

Flagship Projects

Project 1 – E-commerce Order & Customer Analytics Pipeline Mandatory

Domain: Online retail / marketplace

Ingest orders, customers, products → dimensional model → dbt + tests → orchestrated incremental pipeline → data quality → cloud landing.

Why it wins interviews: Universal business domain. Demonstrates modeling, reliability, and business metrics.

Project 2 – Ride-Hailing / Logistics Trip Pipeline Strong Second

Domain: Transportation / logistics

High-volume public trip data → late-arriving data handling → dimensional model → dbt + orchestration + monitoring.

Why it wins interviews: Industry benchmark dataset. Shows you can handle real-world scale and messiness.

Project 3 – SaaS Product Usage & Subscription Pipeline Excellent Alternative

Domain: SaaS / product analytics

Event + subscription data → user/activation/churn models → key SaaS metrics in dbt.

Why it wins interviews: Extremely relevant to SaaS companies (major employers of data engineers).

Detailed Daily Plan

Week 1 – Environment & Docker

Day 1: Install Docker Desktop. Watch TechWorld with Nana – Docker Tutorial for Beginners (first half). Run hello-world, nginx, and a basic Python container.
Day 2: Learn Dockerfile syntax. Vibe-code a simple Python app → understand every line. Build and run it.
Day 3: Volumes, networks, and port mapping. Practice with a Postgres container.
Day 4: Docker Compose fundamentals. Create a multi-service docker-compose.yml.
Day 5–6: Build your permanent local development stack (Python + Postgres + volumes). Document it thoroughly.
Day 7: Review + write a short reflection on reproducibility.

Deliverable: Fully working containerized local environment.

Week 2 – Advanced SQL

Day 1–2: Complete the free DataLemur SQL Tutorial. Practice SELECT, JOINs, GROUP BY, CASE.
Day 3–4: Window functions deep dive (ROW_NUMBER, RANK, LAG/LEAD, running totals). Solve 8–10 medium questions on DataLemur.
Day 5: CTEs, subqueries, and basic query performance (EXPLAIN).
Day 6–7: Solve 10+ mixed medium/hard questions. Push clean, well-commented solutions to GitHub.

Deliverable: 15–20 documented SQL solutions on GitHub.

Extra practice: Mode Analytics SQL Tutorial

Week 3 – Data Modeling

Day 1–2: Study Kimball dimensional modeling (star schema, fact vs dimension, grain, SCD basics). Start with Kimball Group free articles.
Day 3: Design the full star schema for Project 1 (E-commerce).
Day 4–5: Write complete DDL in your Dockerized Postgres and load sample data.
Day 6–7: Write analytical queries against your model. Document the design decisions.

Deliverable: Project 1 dimensional model + DDL complete.

Week 4 – Production-Grade Python

Day 1–2: Typing, logging, configuration management, environment variables, modular structure.
Day 3–4: Robust error handling and pytest. Vibe-code then heavily refactor.
Day 5–7: Build a reusable, tested ingestion package for Project 1 and containerize it.

Deliverable: Production-quality ingestion module inside Docker.

Week 5 – Data Quality & Idempotency

Day 1–2: Core data quality concepts (completeness, uniqueness, validity, consistency).
Day 3–5: Implement validation checks and make the Project 1 pipeline idempotent.
Day 6–7: Practice safe re-runs and basic backfill logic. Document failure modes.

Deliverable: Quality + idempotency layer for Project 1.

Week 6 – First End-to-End Local Pipeline

Day 1–4: Build complete extract → transform → load for Project 1 inside Docker Compose.
Day 5–7: Add logging, quality checks, configuration, and simple scheduling.

Deliverable: Working local Project 1 pipeline.

Week 7 – dbt Core

Day 1–2: Install dbt Core + Postgres adapter. Complete the free dbt Fundamentals course.
Day 3–7: Build the full dbt project for Project 1 (models, sources, tests, documentation, incremental models).

Deliverable: Project 1 dbt layer complete with tests and docs.

Docs: Official dbt Documentation

Week 8 – Orchestration

Day 1–3: Complete the Prefect official tutorial (flows, tasks, retries, logging, scheduling).
Day 4–7: Convert Project 1 into fully orchestrated Prefect flows with proper error handling and monitoring.

Deliverable: Project 1 fully orchestrated and production-ready locally.

Alternative: Apache Airflow Getting Started

Week 9 – Integration & Second Project

Day 1–4: Final polish of Project 1 (architecture diagram, professional README, monitoring notes).
Day 5–7: Begin Project 2 (Ride-Hailing/Logistics) — reuse your Docker + dbt + orchestration patterns. Focus on volume and late-arriving data.

Deliverable: Polished Project 1 + Project 2 foundation started.

Week 10 – Cloud Extension

Day 1–3: Set up Google BigQuery free tier (or AWS Free Tier). Move key parts of Project 1 to the cloud.
Day 4–7: Continue Project 2 or begin Project 3 (SaaS) using the same modern stack.

Deliverable: Cloud version of flagship project + progress on second project.

Week 11 – Portfolio Polish

Day 1–4: Finalize 2–3 projects. Write excellent READMEs, create architecture diagrams, record short Loom walkthroughs.
Day 5–7: Clean GitHub profile and create a simple portfolio overview.

Deliverable: Hiring-ready public portfolio.

Week 12 – Interview Prep & Launch

Day 1–3: Daily live SQL practice on DataLemur + pipeline design questions.
Day 4–5: Practice explaining your own projects out loud (record yourself).
Day 6–7: Apply to 10–15+ roles (Turing, Andela, Remote4Africa, LinkedIn, Upwork data roles, etc.).

Deliverable: Active job applications underway.
