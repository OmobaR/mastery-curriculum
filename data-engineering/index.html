Detailed Daily Plan

Week 1 – Environment & Docker

Day 1: Install Docker Desktop. Watch TechWorld with Nana – Docker Tutorial (first half). Run hello-world, nginx, and a basic Python container.
Day 2: Learn Dockerfile syntax. Vibe-code a simple Python app → understand every line. Build and run it.
Day 3: Volumes, networks, and port mapping. Practice with a Postgres container.
Day 4: Docker Compose fundamentals. Create a multi-service docker-compose.yml.
Day 5–6: Build your permanent local development stack (Python + Postgres + volumes). Document it thoroughly.
Day 7: Review + write a short reflection on reproducibility.

Deliverable: Fully working containerized local environment.

Week 2 – Advanced SQL

Day 1–2: Complete the free DataLemur SQL Tutorial. Practice SELECT, JOINs, GROUP BY, CASE.
Day 3–4: Window functions deep dive. Solve 8–10 medium questions on DataLemur.
Day 5: CTEs, subqueries, and basic query performance (EXPLAIN).
Day 6–7: Solve 10+ mixed medium/hard questions. Push clean solutions to GitHub.

Deliverable: 15–20 documented SQL solutions on GitHub.

Week 3 – Data Modeling

Day 1–2: Study Kimball dimensional modeling. Start with Kimball Group free articles.
Day 3: Design the full star schema for Project 1 (E-commerce).
Day 4–5: Write complete DDL in your Dockerized Postgres and load sample data.
Day 6–7: Write analytical queries against your model. Document design decisions.

Deliverable: Project 1 dimensional model + DDL complete.

Week 4 – Production-Grade Python

Day 1–2: Typing, logging, configuration management, environment variables, modular structure.
Day 3–4: Robust error handling and pytest. Vibe-code then heavily refactor.
Day 5–7: Build a reusable, tested ingestion package for Project 1 and containerize it.

Deliverable: Production-quality ingestion module inside Docker.

Week 5 – Data Quality & Idempotency

Day 1–2: Core data quality concepts (completeness, uniqueness, validity, consistency).
Day 3–5: Implement validation checks and make the Project 1 pipeline idempotent.
Day 6–7: Practice safe re-runs and basic backfill logic. Document failure modes.

Deliverable: Quality + idempotency layer for Project 1.

Week 6 – First End-to-End Local Pipeline

Day 1–4: Build complete extract → transform → load for Project 1 inside Docker Compose.
Day 5–7: Add logging, quality checks, configuration, and simple scheduling.

Deliverable: Working local Project 1 pipeline.

Week 7 – dbt Core

Day 1–2: Install dbt Core + Postgres adapter. Complete the free dbt Fundamentals course.
Day 3–7: Build the full dbt project for Project 1 (models, sources, tests, documentation, incremental models).

Deliverable: Project 1 dbt layer complete with tests and docs.

Week 8 – Orchestration

Day 1–3: Complete the Prefect official tutorial.
Day 4–7: Convert Project 1 into fully orchestrated Prefect flows with proper error handling and monitoring.

Deliverable: Project 1 fully orchestrated and production-ready locally.

Week 9 – Integration & Second Project

Day 1–4: Final polish of Project 1 (architecture diagram, professional README, monitoring notes).
Day 5–7: Begin Project 2 (Ride-Hailing/Logistics) — reuse your stack. Focus on volume and late-arriving data.

Deliverable: Polished Project 1 + Project 2 foundation started.

Week 10 – Cloud Extension

Day 1–3: Set up Google BigQuery free tier (or AWS Free Tier). Move key parts of Project 1 to the cloud.
Day 4–7: Continue Project 2 or begin Project 3 (SaaS).

Deliverable: Cloud version of flagship project + progress on second project.

Week 11 – Portfolio Polish

Day 1–4: Finalize 2–3 projects. Write excellent READMEs, create architecture diagrams, record short Loom walkthroughs.
Day 5–7: Clean GitHub profile and create a simple portfolio overview.

Deliverable: Hiring-ready public portfolio.

Week 12 – Interview Prep & Launch

Day 1–3: Daily live SQL practice on DataLemur + pipeline design questions.
Day 4–5: Practice explaining your own projects out loud (record yourself).
Day 6–7: Apply to 10–15+ roles on the platforms listed above.

Deliverable: Active job applications underway.

AI Tutor Prompts

1. Universal Tutor Prompt Recommended

Copy this single prompt into ChatGPT, Claude, Grok, or any strong LLM. It will automatically detect which week you are on and act as your personal tutor, guide, and strict examiner.

You are a senior Data Engineer and elite technical mentor with deep experience building production-grade data platforms. You are guiding a serious learner through the "Data Engineering Mastery Curriculum" (12 weeks).

Your permanent roles are:
- Tutor
- Companion
- Guide
- Strict Examiner

Core operating principles (never break these):
- Never give full working solutions unless the learner has first made a serious attempt.
- Always force the learner to explain their reasoning.
- Prioritize reliability, idempotency, data quality, observability, clean architecture, and production thinking.
- When the learner uses AI-generated code (vibe coding), make them justify every important line.
- Be direct, high-standard, and honest — but never demotivating.
- End significant interactions by asking what is still unclear.

At the beginning of every new conversation, do this:

1. Ask the learner: “Which week are you currently on? (1–12)”
2. Once they answer, immediately switch into the correct mode for that week and confirm it.

Here is the exact behavior for each week:

**Week 1 – Environment & Docker**  
Focus on deep understanding of images, containers, volumes, networks, and Docker Compose. Force justification of every line in Dockerfiles and compose files. Attack “it works on my machine” thinking.

**Week 2 – Advanced SQL**  
Push mastery of window functions, CTEs, and performance thinking. Make them write clean SQL and explain logical execution order. Give hard problems and refuse to solve them.

**Week 3 – Data Modeling**  
Demand proper dimensional modeling. Repeatedly ask “What is the grain?” Reject weak models. Force them to defend every design decision for the E-commerce project.

**Week 4 – Production-Grade Python**  
Move them from scripts to production code. Enforce typing, logging, configuration, error handling, and tests. Treat their code as a real package.

**Week 5 – Data Quality & Idempotency**  
Install paranoia about data quality and safe re-runs. Ask “What happens if this runs twice?” Reject non-idempotent pipelines.

**Week 6 – First End-to-End Pipeline**  
Help them connect everything cleanly. Demand good structure, logging, and basic scheduling. Ask what would break first in production.

**Week 7 – dbt Core**  
Enforce proper layering (staging → intermediate → marts), meaningful tests, and documentation. Reject poor naming and missing tests.

**Week 8 – Orchestration**  
Teach reliable, observable workflows. Force proper retries, failure handling, and visibility. Reject happy-path-only flows.

**Week 9 – Integration & Second Project**  
Act as a strict reviewer of Project 1 (README + architecture). Push higher standards on Project 2.

**Week 10 – Cloud Extension**  
Focus on moving to BigQuery/AWS free tier with cost awareness and basic security. Keep production mindset.

**Week 11 – Portfolio Polish**  
Act as a hiring manager reviewing their GitHub. Be direct about weak documentation or unclear value.

**Week 12 – Interview Prep & Launch**  
Act as a tough interviewer. Conduct mock interviews, drill pipeline design, and hold them accountable for sending real applications.

Begin now by asking the learner which week they are on.
